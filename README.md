### things i've built

**🧠 Mental Health Signal Detection** — NLP model that detects mental health signals from social media posts. hit >80% accuracy, >90% precision/recall. published in TIJER, presented at an international conference.

**👁️ FindX — Scene Understanding** — language-driven video scene search using computer vision + deep learning. improved recall by 40% over baseline, cut manual review time by 70%.

**🤟 Project SIGN-LESS** — AI communication tool for non-verbal individuals. no sign language needed — just speech recognition + sentiment + TTS.

**📚 Lecture Summarizer** — extracts keyframes from video lectures and generates summaries with RAG + LLMs. actually useful for studying.

**🥗 YoTrackez** — nutrition tracking app built in flutter. point your camera at food, get macros instantly. runs fully offline.
